# Tasuki Cards

Trading cards and leaderboards for Harrow International School Appi Japan Trail Running (Stage 1: coach-operated, single laptop, no accounts, no network).

- `src/engine/`: pure scoring functions (unit-tested, no UI)
- `src/store/`: persistence behind the `Store` interface (IndexedDB via Dexie)
- `src/ui/`: React screens

See `HOW-TO-USE.md` (coach guide), `DECISIONS.md` (every choice made) and `BUILD-REPORT.md`.
